📊 Kaggle · HuggingFace · Ollama
Manual setup instructions for dataset access, model downloads, and local LLM setup
📊
Kaggle API Setup
Download datasets for model training or evaluation
  1. Create free account at https://www.kaggle.com
  2. Click Profile icon → Settings → API → Create New Token
  3. A file kaggle.json downloads automatically
  4. Place the file at the required path:
# Windows — required location: C:\Users\YOUR_USERNAME\.kaggle\kaggle.json # PowerShell commands: New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.kaggle" Copy-Item Downloads\kaggle.json "$env:USERPROFILE\.kaggle\kaggle.json" # Install CLI and test pip install kaggle kaggle datasets list # Download a dataset kaggle datasets download -d USERNAME/DATASET -p ./data kaggle competitions download -c COMPETITION -p ./data
⚠ NEVER commit kaggle.json to Git. Add .kaggle/ to your .gitignore.
🤗
HuggingFace Hub Setup
Required for Pyannote, Whisper, and other gated models
  1. Register at https://huggingface.co/join
  2. Settings → Access Tokens → New Token (type: Read)
  3. Accept gated model licenses for pyannote models
pip install huggingface_hub # Option A — interactive login (saves to ~/.huggingface/token) huggingface-cli login # Option B — environment variable HUGGINGFACE_TOKEN=hf_YOUR_TOKEN # add to .env # Download specific models huggingface-cli download pyannote/speaker-diarization-3.1 huggingface-cli download Systran/faster-whisper-large-v3 # View cached models huggingface-cli scan-cache
🦙
Ollama — 100% Offline Local LLM
No API key, no cost. Run llama3/mistral/qwen2 locally for translation.
# 1. Download from https://ollama.ai — Windows .exe installer # Ollama runs as a background Windows service on port 11434 # 2. Pull a translation model ollama pull llama3.2:3b # ~2GB — fast, good quality ollama pull mistral:7b # ~4GB — better for EN→BN ollama pull qwen2.5:7b # ~4GB — best for Asian languages ollama pull aya-expanse:8b # ~5GB — multilingual specialist # 3. Configure in .env as an unofficial OpenAI-compatible endpoint: UNOFFICIAL_1_URL=http://localhost:11434/v1 UNOFFICIAL_1_KEY=ollama UNOFFICIAL_1_MODEL=llama3.2:3b UNOFFICIAL_1_NAME=local_ollama PROVIDER_PRIORITY=unofficial,openrouter,gemini # 4. Test connection ollama run llama3.2:3b "Translate to Bangla: Hello World" curl http://localhost:11434/api/tags
✅ With Ollama: ALL translation runs 100% OFFLINE. No API costs ever.
